Serventia

Esse site foi criado para servir de demonstração prática do curso "Programador Web" e provavelmente ficará exposto na internet.

Conhecimentos gerais

O curso em si, capacita o aluno a criar, programar e gerenciar sites e aplicações para a internet com aulas 100% práticas e ótima tutoria.
O que é ensinado:

  • HTML: Estruturação de textos, imagens, links e seções.
    • O HTML serve para estruturar e organizar o conteúdo da página. Ele não é uma linguagem de programação,. mas sim uma linguagem de marcação. É ele quem diz ao navegador o que é cada elemento do site. Basicamente servindo de estrutura.

  • CSS: cores, fontes, espaçamentos e layouts.
    • O CSS serve para dar estilo, beleza e layout ao conteúdo estruturado pelo HTML. Sem o CSS, todos os sites seriam apenas textos pretos em fundo branco alinhados à esquerda. Uma piada interna que é muito usada é de que o CSS é a "maquiagem" do site.

  • JavaScript: Introdução à linguagem para adicionar animações e validação de formulários).
    • O JavaScript serve para criar interatividade e dinamismo. Ele roda diretamente no navegador do usuário para fazer o site "pensar" e reagir a ações (como os botões desse mesmo site).

O que aprendi por fora:

Design Responsivo: Técnicas para fazer com que o site se adapte perfeitamente a telas de computadores, tablets e celulares. Propriedades de Estilização: É o nome de comandos como o box-shadow (sombreamento) e border-bottom (linha abaixo do título)
